# План 80 сессий — финальная реализация киоска самообслуживания

Дата: 07.11.2025
Версия: 3.0
Автор: команда проекта

## Цели
- Сформировать единый Android-монореп (`android/`) c модулями `app`, `core`, `feature-*`, `platform`, интегрированными нативными библиотеками и сервисными слоями.
- Доставить финальную функциональность OBD-II, толщиномера, платежей, отчётности и наблюдаемости так, чтобы установленный размер APK ≥ **60 MB чистого APK** за счёт встроенных моделей, офлайн-данных и нативных компонентов.
- Интегрировать Supabase, Green API, почтовые/SMS шлюзы и локальные отчёты с полной трассировкой секретов.
- Сохранить минималистичный UI для клиента, обеспечив автоматизацию фоновых процессов, DevOps-пайплайнов и автономных обновлений.

## Ключевые результаты
- APK ≥ 60 MB, stable 30 FPS UI, время диагностики < 90 секунд.
- Кросс-платформенный SDK пасстру/OBD, генератор отчётов и платежный контур в Kotlin.
- Завершённый реестр секретов (`09-docs/02-application/security/credential-inventory.md`) и процедуры ротации.
- CI/CD c lint/test/assemble, интеграция телеметрии и таблица KPI.

## Правила проведения
- Каждая сессия 2–3 часа с фиксацией входа, результата и владельца.
- После каждого блока из 10 сессий — ретроспектива и обновление метрик.
- Документация в рамках плана не расширяется; фиксируются только технические артефакты (код, конфигурации, тесты).
- Минимальный объём выполнения: одновременно держим в работе и доводим до статуса «Выполнено» не менее пяти задач из плана (пять сессий). Каждый пользовательский запрос должен продвигать максимально допустимое количество сессий, фиксируя результаты по всем затронутым пунктам.
- Используем уникальный рабочий запрос (см. `.github/copilot-instructions.md`), который запускает выполнение, тестирование и отчётность по текущей сессии.

## Контроль и метрики
- APK size ≥ 60 MB (контроль на сессиях 10, 20, 40, 60, 80).
- Crash-free sessions ≥ 99%, reconnect rate ≥ 95%, edge-cache hit rate ≥ 80%.
- Среднее время диагностики < 90 секунд, время выдачи толщиномера < 30 секунд.
- Покрытие тестами: unit ≥ 70%, instrumented ≥ 40%.
- Полнота телеметрии и аудит-логов; регулярность ротации секретов ≤ 90 дней.
