# Приложения терминала

Каталог содержит приложения уровня Application для киоска самообслуживания. Структура синхронизирована с архитектурными правилами из `.github/instructions`.

| Директория            | Назначение                                                                                                                                               |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `android-kiosk/`      | Android-приложение с WebView-оболочкой для фронтенда киоска. Содержит BLE-инфраструктуру и UX потоки измерения/диагностики.                              |
| `kiosk-shell/`        | Node.js-оболочка и вспомогательные сервисы киоска (Electron/Node), включающие HTTP API, интеграции устройств и модуль отчётов.                           |
| `kiosk-agent/`        | Актуальная версия локального агента (TypeScript, ESM) для управления устройствами, платежами и отчётами. Источник перемещён из `apps/kiosk/agent`.       |
| `kiosk-agent-legacy/` | Архив legacy-версий агента и Android-шаблонов (до унификации). Содержит исторические Gradle проекты и Bluetooth SPP примеры; в продакшн не используется. |

## Правила работы

- Соблюдайте дев-режимы (`DEV`, `QA`, `PROD`) для агента и оболочки в соответствии с `instructions.instructions.md`.
- Перед внесением изменений прогоняйте линтеры и тесты:
  - `npm --prefix 03-apps/02-application/kiosk-agent test`
  - `npm --prefix 03-apps/02-application/kiosk-shell/agent run lint`
  - `./gradlew` внутри `android-kiosk/` для проверки Android модулей (без коммита артефактов из `build/`).
- Архив `kiosk-agent-legacy/archives/` хранит зависимые файлы прошлого - не модифицируйте без отдельного задания.
